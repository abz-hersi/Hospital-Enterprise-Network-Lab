\# AzizCare Hospital Enterprise Network



\## Project Overview



This project is based on designing and building a hospital network from scratch.



The main goal is to create a secure and organised network where different departments like Doctors, Nurses, Finance, IT, Servers, CCTV and Guest Wi-Fi are separated and managed properly.



I will be documenting:



\- Why I chose each design

\- How I configured it

\- How I tested it

\- Problems that can happen

\- How I troubleshot them



The project will include VLANs, routing, switching, firewalls, DHCP, DNS, wireless, redundancy and security.



The main aim is to make the lab as close as possible to a real enterprise environment.
